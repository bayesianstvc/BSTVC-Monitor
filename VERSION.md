# BSTVC Monitor v0.5.7

Release date: 2026-08-09

This release packages the validated v0.5.7 desktop build for monitoring `inla.exe` during BSTVC/INLA modelling.

Highlights:

- English dashboard by default with one-click Chinese translation.
- Whole-machine 0–100% CPU view aligned to the Windows Task Manager process perspective.
- Average CPU-first summaries, GB memory display, per-PID start time/runtime identity, and ended-process retention.
- Independent sampling and page refresh controls, with a 5-second sampling default.
- Bounded recent browser cache while complete CSV data remains on disk.
- Worker-backed analysis, health checks, safe reconnect/recovery controls, stage hints, and long-run integrity summaries.
- Full experiment package export with charts, localized HTML report, summaries, and raw data.
- Cautious resource-performance leader wording, sample-integrity status, ended-record retention levels, same-phase comparison, threshold evidence, export preflight, adaptive desktop density, sticky live status, and PID action drawer.
- Compact BSTVC-logo header with a reduced visual backdrop for long-running desktop monitoring.
- Automatic phase detection collapsed on first load; its status ribbon is attached to the synchronized timeline navigator.
- Consistent expand/collapse behavior for composite evaluation, advanced monitoring, and page problem handling.
- KPI hover/focus explanations, per-PID adaptive CPU threshold controls, and current English/Chinese desktop screenshots.
- Portable launcher, local-only storage, accuracy guidance, issue templates, and AGPL-3.0 licensing.

This is a research-support monitor. Always validate model convergence, result quality, and completed runtime in addition to resource utilization.
