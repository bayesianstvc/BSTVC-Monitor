# BSTVC Monitor v0.5.0

Release date: 2026-08-02

This release packages the current validated local preview as an English-first, portable Windows tool for monitoring `inla.exe` during BSTVC/INLA modelling.

Highlights:

- English dashboard by default with one-click Chinese translation.
- Whole-machine 0–100% CPU view aligned to the Windows Task Manager process perspective.
- Average CPU-first summaries, GB memory display, per-PID start time/runtime identity, and ended-process retention.
- Independent sampling and page refresh controls, with a 5-second sampling default.
- Bounded recent browser cache while complete CSV data remains on disk.
- Worker-backed analysis, health checks, safe reconnect/recovery controls, stage hints, and long-run integrity summaries.
- Full experiment package export with charts, localized HTML report, summaries, and raw data.
- Portable launcher, local-only storage, screenshots, accuracy guidance, issue templates, and AGPL-3.0 licensing.

This is a research-support monitor. Always validate model convergence, result quality, and completed runtime in addition to resource utilization.
