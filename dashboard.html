常见问题与故障恢复

采样间隔和页面刷新有什么区别？ 采样间隔由监视器采集数据；页面刷新只控制网页重新分析和绘图，两者可以独立设置。

为什么结束进程仍保留在页面？ 结束记录会保留在历史曲线和评价中，并明确标为已结束；这不是仍在运行。

页面停止更新怎么办？ 先重新连接监视器，再查看健康检查；清理页面缓存只清理浏览器内存，不删除 CSV。

怎样核对准确性？ 优先用主曲线和 PID 卡片的当前 CPU、平均 CPU 与任务管理器进程页逐时刻对照。

主曲线和 PID 曲线只使用 `cpu_pct_total`（任务管理器可对照口径）。高级诊断中的 Windows 性能计数器和核心等效值以单个逻辑核心=100%，用于判断并行度，不用于和主曲线直接比较。任务管理器与采集器的刷新窗口仍可能造成瞬时差异；校准因子可在高级诊断中核对。首个采样点用于建立 CPU 时间基线，通常显示为 warmup。
