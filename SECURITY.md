# Security policy

## Scope

BSTVC Monitor is a local Windows tool. The collector binds to loopback (`127.0.0.1`) and stores run data in the current user’s local application data directory unless another path is selected.

## Reporting a security issue

Please do not publish credentials, private model data, or an exploitable proof of concept in a public issue. Use a private GitHub security channel if one is available for the repository; otherwise contact the maintainer privately through the public project profile and provide the smallest reproducible description possible.

The project does not request passwords, tokens, or model files. Never include those in an issue or support request.
